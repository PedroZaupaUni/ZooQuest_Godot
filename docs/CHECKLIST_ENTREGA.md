# Checklist de entrega

## Materiais

- [ ] Repositório público atualizado: `https://github.com/PedroZaupaUni/ZooQuest_Godot`.
- [ ] Projeto Godot completo na branch `main`.
- [ ] Relatório em `docs/relatorio/RELATORIO_DESENVOLVIMENTO_ZOOQUEST.pdf`.
- [ ] Arquivo editável do relatório em `docs/relatorio/RELATORIO_DESENVOLVIMENTO_ZOOQUEST.docx`.
- [ ] Vídeo de demonstração dentro do limite definido pela atividade.
- [ ] Link jogável incluído na entrega quando a publicação Web estiver disponível.
- [ ] Postagem individual realizada por cada integrante quando exigida pela atividade.

## Verificação técnica

- [ ] `project.godot` abre no Godot 4.7.2.
- [ ] F5 inicia pelo menu principal.
- [ ] A jornada chega ao encerramento sem abrir cenas manualmente.
- [ ] Caminhos de acerto e erro funcionam nas três fases.
- [ ] Controles por teclado funcionam.
- [ ] Interações por mouse funcionam onde previstas.
- [ ] Pontuação máxima possível é 90.
- [ ] Jogar novamente reinicia estado e fluxo.
- [ ] Voltar ao menu funciona.
- [ ] Debugger termina sem erros vermelhos.
- [ ] `./scripts/run_validation.sh` termina com sucesso.
- [ ] `./scripts/run_godot_smoke.sh` termina com sucesso no ambiente de apresentação.
- [ ] GitHub Actions da `main` está verde.

## Conferência de apresentação

- [ ] Capturas ou gravação mostram as três fases.
- [ ] O grupo sabe explicar o ciclo pergunta -> escolha -> feedback -> progresso.
- [ ] O grupo sabe explicar a separação entre `core`, `data`, `ui`, `characters` e `minigames`.
- [ ] O repositório e o relatório exibidos na demonstração correspondem à mesma versão entregue.
