# Roadmap

O roadmap registra melhorias desejáveis sem definir compromisso de data ou versão.

## Experiência e interface

- ampliar animações dos personagens;
- revisar contraste e legibilidade em diferentes resoluções;
- refinar feedback visual das escolhas;
- avaliar um menu de pausa sem alterar o fluxo pedagógico.

## Acessibilidade

- controle de volume;
- indicação de estado que não dependa apenas de cor;
- revisão de tamanho de fonte e áreas clicáveis;
- revisão de navegação para teclado e mouse.

## Conteúdo educacional

- revisão pedagógica das perguntas;
- expansão do banco de questões;
- níveis adicionais de dificuldade;
- novas explicações para respostas incorretas.

## Qualidade

- ampliar testes automatizados para interações específicas de cada mini-game;
- registrar testes manuais de apresentação em mais de um equipamento;
- revisar periodicamente dependências e versão do Godot.

## Distribuição

- preparar exportação Web quando a versão jogável pública fizer parte da entrega;
- validar carregamento, áudio e controles no navegador antes da publicação.
