# Checklist da entrega no Classroom

## Itens da atividade de Desenvolvimento

- [ ] Link do repositório GitHub atualizado.
- [ ] Projeto Godot completo no repositório.
- [ ] Link da versão jogável, somente se já estiver disponível.
- [ ] PDF `docs/relatorio/RELATORIO_DESENVOLVIMENTO_ZOOQUEST.pdf`.
- [ ] Vídeo não listado de até 7 minutos.
- [ ] Todos os integrantes realizaram a postagem individual solicitada.

## Conferência técnica antes da postagem

- [ ] `project.godot` abre no Godot 4.x.
- [ ] F5 inicia pelo menu.
- [ ] O fluxo chega ao encerramento sem abrir cenas manualmente.
- [ ] Erro e acerto foram testados nas três fases.
- [ ] Pontuação máxima possível é 90.
- [ ] Jogar novamente e voltar ao menu funcionam.
- [ ] Debugger sem erros vermelhos.
- [ ] `python3 scripts/validate_repository.py` retorna PASS.
- [ ] O ZIP foi extraído antes de abrir o projeto.
