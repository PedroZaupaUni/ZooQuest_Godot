# Fontes documentais preservadas

Os arquivos desta pasta foram fornecidos pelo grupo e utilizados como base para o projeto.

## Precedencia adotada

1. `GDD_ZooQuest.pdf` e `Visao_ZooQuest.pdf`: definem o jogo atual.
2. `Documentacao_Gameplay_e_Fluxos.docx`: registra o fluxo continuo, interacoes e ciclo principal.
3. `Casos_de_Uso_ZooQuest.asta`: modelo editavel do diagrama.
4. `Orientacoes_UniFil_Jogos.pdf`: requisitos institucionais.
5. `Projeto_PI_FindIt_Historico.pdf`: proposta inicial, preservada apenas como historico.

Quando a proposta antiga FindIt diverge do ZooQuest, prevalece a documentacao atual do ZooQuest.
