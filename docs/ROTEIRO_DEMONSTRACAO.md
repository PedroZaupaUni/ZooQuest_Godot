# Roteiro de demonstração

A tabela abaixo organiza uma apresentação de até sete minutos sem definir falas prontas para os integrantes.

| Tempo | Tópico | Evidência sugerida |
|---:|---|---|
| 0:00-0:35 | Objetivo do ZooQuest, público infantil e contexto educacional | menu e identidade do projeto |
| 0:35-1:05 | Narrativa e ciclo pergunta -> escolha -> feedback | diagrama de fluxo |
| 1:05-2:15 | Sapo Matemático | seleção, uma tentativa incorreta e uma correta |
| 2:15-3:25 | Pássaro Lógico | troca de faixa, mouse e validação de resposta |
| 3:25-4:35 | Minhoca das Escolhas | movimentação, clique e coleta de fruta-resposta |
| 4:35-5:10 | Encerramento e rejogabilidade | pontuação, jogar novamente e voltar ao menu |
| 5:10-6:05 | Arquitetura | `core/main.gd`, `questions.json` e `story_flow.json` |
| 6:05-6:40 | Processo de qualidade | GitHub Actions e testes do Godot |
| 6:40-7:00 | Participação do grupo e conclusão | repositório e relatório |

## Preparação

Antes da gravação:

- execute `tests/manual/ROTEIRO_TESTE_FUNCIONAL.md`;
- confirme a CI verde na `main`;
- verifique áudio, resolução, microfone e captura de tela;
- selecione previamente uma resposta incorreta e uma correta para cada demonstração;
- mantenha o tempo reservado para todos os integrantes exigidos pela atividade;
- confira o relatório e a versão do repositório que serão exibidos.
