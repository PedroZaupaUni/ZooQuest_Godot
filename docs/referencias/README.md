# Documentos de referência

Esta pasta preserva os materiais acadêmicos que fundamentam o escopo e a documentação do ZooQuest.

| Arquivo | Uso no projeto |
|---|---|
| `VISAO_ZOOQUEST.pdf` | visão, público, objetivos e escopo do jogo |
| `GDD_ZOOQUEST.pdf` | mecânicas e regras de gameplay |
| `DOCUMENTACAO_GAMEPLAY_E_FLUXOS.docx` | fluxo contínuo, interações e comportamento das fases |
| `CASOS_DE_USO_ZOOQUEST.asta` | modelo editável do diagrama de casos de uso |
| `ORIENTACOES_UNIFIL_JOGOS.pdf` | requisitos institucionais da atividade |
| `PROJETO_PI_FINDIT_HISTORICO.pdf` | proposta anterior mantida apenas como histórico do trabalho |
| `CLASSROOM_VERSAO_FUNCIONAL.png` | registro visual da atividade no ambiente acadêmico |

Quando um documento histórico divergir da visão, do GDD ou da documentação funcional atual do ZooQuest, a documentação atual do ZooQuest deve ser usada como referência do produto implementado.
