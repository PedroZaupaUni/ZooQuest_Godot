# Validação

- `VALIDATION_REPORT.json`: resultado da validação estática automatizada.
- `GODOT_RUNTIME_ATTEMPT.txt`: registro honesto da tentativa de executar o smoke test no ambiente de geração.
- `scripts/run_godot_smoke.sh`: executa importação headless e o smoke test quando o Godot 4.x estiver disponível.
- `tests/manual/ROTEIRO_TESTE_FUNCIONAL.md`: validação completa da experiência no editor.

A validação estática não substitui a execução no motor Godot.
