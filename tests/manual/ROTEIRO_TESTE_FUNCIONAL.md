# Roteiro de teste funcional no Godot

Execute o projeto com F5 e marque cada item.

## Inicializacao

- [ ] T01 - O projeto abre sem erro de parse.
- [ ] T02 - F5 exibe o menu principal.
- [ ] T03 - O botao Como Jogar abre e fecha as instrucoes.
- [ ] T04 - O botao Jogar inicia a narrativa.

## Narrativa e transformacao do sapo

- [ ] T05 - As tres mensagens iniciais avancam por botao e ENTER/ESPACO.
- [ ] T06 - A transformacao humano -> sapo aparece.
- [ ] T07 - Continuar abre a fase do sapo.

## Sapo Matematico

- [ ] T08 - Esquerda/direita e A/D mudam a vitoria-regia destacada.
- [ ] T09 - ESPACO anima o salto.
- [ ] T10 - Uma resposta incorreta exibe explicacao e repete a pergunta.
- [ ] T11 - Uma resposta correta soma 10 pontos e avanca.
- [ ] T12 - As tres perguntas podem ser concluídas.
- [ ] T13 - O personagem retorna a forma humana.

## Passaro Logico

- [ ] T14 - A narrativa intermediaria e a transformacao aparecem.
- [ ] T15 - Cima/baixo e W/S mudam de faixa.
- [ ] T16 - A barreira se aproxima continuamente.
- [ ] T17 - Escolha incorreta causa feedback de colisao e repeticao.
- [ ] T18 - Escolha correta soma pontos e avanca.
- [ ] T19 - As tres perguntas podem ser concluídas.
- [ ] T20 - O personagem retorna a forma humana.

## Minhoca das Escolhas

- [ ] T21 - Setas e WASD movimentam a minhoca.
- [ ] T22 - Encostar ou clicar em uma fruta registra a escolha.
- [ ] T23 - Fruta incorreta exibe explicacao e repete a pergunta.
- [ ] T24 - Fruta correta soma pontos e avanca.
- [ ] T25 - As tres perguntas podem ser concluídas.
- [ ] T26 - O personagem retorna a forma humana.

## Encerramento e rejogabilidade

- [ ] T27 - A tela final mostra pontos, acertos e erros.
- [ ] T28 - Jogar Novamente zera os dados e reinicia a narrativa.
- [ ] T29 - Voltar ao Menu funciona.
- [ ] T30 - O Debugger termina sem erro vermelho.
